# 📌 Comment ça marche

Salut @downjones 👋 et tous les motards du serveur !

Ce salon, c'est la **boîte à idées de Cono Moto**. Une idée, un bug, un truc qui t'agace en roulant ? C'est ici que ça se passe.

**🏍️ Depuis l'appli (le plus simple)**
1. Ouvre **Réglages › Communauté**
2. Choisis **Proposer une idée** ou **Signaler un bug**
3. Mets un titre, explique ton idée (ou ce qui s'est passé) et ajoute une capture d'écran si ça aide
4. Appuie sur **Envoyer sur Discord** : ta demande arrive ici, avec la version de l'appli et le modèle de ton téléphone (super utile pour les bugs, et tu peux le décocher)

**✍️ Directement sur Discord**
Écris ton idée ou ton bug dans ce salon, en un seul message (une demande par message, c'est plus simple à suivre).

**👍 Vote pour les idées des autres**
Mets un 👍 sous une demande : les plus votées passent en premier.

**🤖 Et ensuite ?**
Un fil s'ouvre sous chaque demande pour en discuter. Chaque matin, Claude (l'IA qui code l'appli avec Marc) lit les nouvelles demandes et te répond dans ce fil : une question s'il manque une info, sinon ce qu'il en fait. Les petites améliorations claires sont codées dans la foulée, Marc valide, et un « ✅ C'est fait » arrive dans le fil quand c'est dans l'appli.

**🐞 Pour un bug bien décrit** : ce que tu faisais, ce qui s'est passé, et ce que tu attendais. Une capture vaut mille mots.

_La version de l'appli avec le bouton « Envoyer sur Discord » sort d'ici une quinzaine de minutes (lien « derniere-version »). Le robot qui ouvre les fils et relaie les réponses est en cours d'installation : les premières réponses arriveront dès qu'il sera branché._
